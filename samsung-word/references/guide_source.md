표준 문서 작성 가이드

□ 목적
- 모든 부서가 일관성 있고 효율적으로 문서를 작성하기 위한 표준
- 형식·용어·스타일 규칙을 정해 작성 시간과 노력을 최소화
- 핵심 위주로 명확히 전달하여 올바른 의사결정 지원

□ 문서 종류
- 일반 양식: 단발성·기타 업무 문서 (예: 장애 보고, 가격 보고, 일정 보고, 출장 보고)
- 전사 공유 양식: 전사·유관부서에 보고·공유·공지되는 문서 (예: 현안회의, 전략회의, 경영계획, 정책서)

□ 공통 작성 규칙
- 폰트는 바탕체 기본으로 작성하고, 별도 글꼴은 지양
- 개조식 문장으로 작성 (불필요한 부분 제거, 핵심만 전달)
  · 서술형 예: "고객은 제품 선택 시 기능 요소를 가장 중요하게 고려하며, 성능 테스트는 필수가 아니라고 판단 중임"
  · 개조식 예: "제품 선택 시 고객은 기능 요소가 중요, 성능 미고려"
- 형용사·부사 표현보다 명확한 수치 데이터를 기반으로 작성
  · 예: "제품 성능 향상 추진" → "제품 성능 30% 향상 추진"
- 구조화된 문단 구성을 위해 블렛포인트와 넘버링 사용 (레벨 순서는 유지)
- 줄간격은 일관되게 적용: 줄간격 1.08배수, 줄 앞간격 0pt, 뒤간격 기본 8pt
  · 표 뒤에 내용을 기술할 경우 줄 앞간격은 기본 8pt
- 문장 내 강조가 필요한 경우 단어에 밑줄과 굵게(Bold) 표시
  · 예: 국내 시장은 '28년까지 연평균 13% 성장 전망
- 데이터 표현이 필요한 경우 표를 사용하고 그래프·그림은 지양
- 별도 텍스트박스·각주·미주는 미사용, 필요 시 꺾임기호(ㄴ, ㄱ)를 줄바꿈(Shift+Enter)하여 추가 내용 표시
- 페이지 번호는 하단에 '1/전체페이지수' 형식으로 표시

□ 레벨별 구조 규칙
  구분        | 1레벨    | 2레벨    | 3레벨  | 4레벨 | 5레벨 | 주석
  기호        | 1,2..   | □       | 1),2) | -     | ·     | ㄴ,ㄱ
  폰트 크기   | 16pt(B) | 14pt(B) | 14pt  | 14pt  | 12pt  | 9pt
  단락/줄간격 | 14pt    | 12pt    | 8pt   | 8pt   | 8pt   | Shift+Enter

□ 전사 공유용 추가 규칙
- 목차 페이지로 문서 전체의 개요와 구조화된 정보 제공
- 문서 여백을 최소화하여 정보 전달 최적화
- 보고서 첫 장 또는 각 단락에 요약 페이지로 핵심 정보 전달
  · 문서의 목적·주장·결론을 간결하게 정리하여 피보고자의 이해도 향상
